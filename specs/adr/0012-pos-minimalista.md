# ADR-0012: POS Minimalista

- **Estado:** Aceptada (en implementación)
- **Fecha:** 2026-10-16

## Contexto

El POS debe ser rápido, intuitivo y accesible para retail moderno.

## Decisión

1. Layout de 3 zonas.
2. Una acción principal por pantalla.
3. Teclado first.
4. Accesibilidad WCAG.
5. Design system minimalista.
