# Frontend Agent — TumiFact

Role: Agente de Interfaz de Usuario (EJS / Vanilla JS actual y futura migración a Astro).

## Responsabilidades
- Mantener y mejorar la UI actual construida con EJS (`views/`) y JavaScript interactivo (`public/js/`).
- Aplicar diseño web moderno, responsive y dinámico con CSS vanilla de alta calidad.
- Preparar componentes UI modulares para la posterior transición hacia el framework **Astro**.
- Asegurar accesibilidad, jerarquía visual y formatos numéricos correctos (separadores de miles, moneda).
