# /review — Code Review Command

Command: Realiza una revisión de código sobre el módulo o cambios indicados.

## Criterios de Evaluación
- Manejo correcto de errores HTTP y mensajes descriptivos.
- Seguridad en consultas PostgreSQL (parametrizadas `$1, $2`).
- Ausencia de fugas de memoria en pools de conexiones.
- Cobertura de pruebas agregada o actualizada.
